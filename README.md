# FOFA 工具箱（Tampermonkey 用户脚本）

从一个「右键排除搜索」小脚本起步，现在已经长成覆盖**精准筛选、批量操作、指纹收藏**三个方面的 FOFA 工具箱：

- **右键排除 / 包含**：结果页上几乎任何元素——组件、favicon、国旗、世界地图、侧栏排名条目、划选文本——右键即可把该项作为条件取反（或包含）追加到当前搜索语句；
- **批量操作**：逐条暂存、或 Alt + 左键拖拽框选一片区域，把一批条件一次性全部排除/包含；
- **指纹收藏库**：把当前搜索语句连同独立 IP 数、产品、类型、国家、Server、Title 等排名信息一键存档，表格式编辑、置顶、一键重搜、JSON/CSV 导出与导入，数据全部存在浏览器本地。

## 一、右键排除 / 包含

右键以下对象会弹出条件菜单（**只在识别到这些目标时才接管右键**，其余位置保持浏览器原生菜单；**Shift + 右键** = 强制原生菜单）：

| 右键对象 | 识别来源 |
|---|---|
| 组件 / 产品链接 | 解码链接自身的 qbase64 |
| favicon 图标 | 图标外层自带的 icon_hash 搜索链接 |
| 国旗图片（结果行 / 侧栏统计） | 相邻的 country 搜索链接 |
| 侧栏世界地图上的国家 | 右键时悬停中的地图 tooltip（国家名 / ISO 代码） |
| 侧栏「相关Icon」图标 | Vue 组件数据中的 icon_hash（按图标 base64 匹配条目，精确值） |
| 侧栏各排名条目（分类 / Server / 网站标题 / 证书组织 / 网站指纹 / 协议 / 端口…） | 条目自带链接的 qbase64 |
| 服务器图标 | 图标所在锚点的文本 |
| IP / 端口 / 城市 / ASN / org / domain / header_hash / TLS 版本等链接 | 链接的 qbase64 |
| 划选文本 | 选区内容（国名/协议名自动识别字段） |

菜单能力：

- **🚫 排除并打开**（回车同）：将条件取反后追加到当前语句；**➕ 包含**在未编辑时沿用 FOFA 原生运算符（保留 `==` 精确匹配语义）；
- 条件在菜单内**可编辑**，改完再排除/包含；
- **📋 复制**：不打开页面，直接复制排除后的完整语句；
- 当前语句里**已存在的条件**（自引用链接，如当前选中的分类）会**就地取反**而不是追加，避免语句自相矛盾；
- 页脚「在本页打开」开关：勾选后在当前标签页内跳转（默认新标签）；
- 新标签页经 `window.open` 打开，保留 opener 关系——Tree Style Tab 等树状标签插件会将其挂为当前标签的**子标签**。

## 二、批量操作

- **📥 暂存**：右键菜单里把条件攒进右下角徽标（跨页面保留），点开面板可随时增删；
- **Alt + 左键拖拽框选**：框住一块区域，自动识别其中所有可排除对象（侧栏排名条目/结果行 favicon/国旗/服务器图标/相关Icon）并入批量面板；
- 面板内一次「全部排除 / 全部包含并打开」；当前语句里已存在的条件在排除时自动就地取反而不是追加。

## 三、指纹收藏库

**收藏（右键菜单 ⭐，或面板「＋ 新建」）时自动抓取：**

- **搜索语句**：当前页完整语句；
- **独立 IP 数**：结果头部「N 条独立 IP」；
- **产品**：语句里的 `app=`/`product=` 同义取值优先；否则用产品排名「第一名+同位数」规则；都没有则留空；
- **类型**：分类排名里的名字（不带数量）；
- **国家/地区**：排名「第一名+同位数」规则（如 美国3000/中国2000/印度999 → 美国、中国）；
- **Server / Title**：各取排名第一；
- **收录时间**：语句里的 `after=`；
- **名称**：仅在产品唯一（语句单产品或排名仅一条）或产品排名第一名位数严格领先时填入，其余留空；
- 「＋ 新建」在结果页同样自动填写，其余页面为空白条目。

**管理面板**（左下角「🗂 指纹库」打开）：

- 表格含名称/搜索语句/IP数/产品/类型/国家/Server/Title/收录时间/厂商/型号/备注列，单元格点击即编辑（失焦保存），可任意新建/删除条目；
- 🔍 直接用该语句搜索；
- 一键导出 JSON / CSV（CSV 带 BOM，Excel 可直接打开）；
- **导入 JSON / CSV**：与本脚本导出的两种格式对称（表头中文列名或英文字段名均可），按**搜索语句去重合并**——语句为空或已存在的条目（忽略空白差异）自动跳过，完成后提示新增/跳过数量；Excel 在中文 Windows 另存的 ANSI/GBK 编码 CSV 也能自动识别；
- **窗口可拖动**：按住标题栏移动（位置会记住），双击标题栏复位居中；
- **fofa.info 首页默认自动打开**（居中偏下显示，手动关闭后本次会话不再弹出）；
- 数据存于浏览器 localStorage。

**内置日期语法与置顶：**

- **`after` 值内可使用内置占位语法**：`YESTERDAY`（昨天）、`LastMonth`（一月前，月末日钳制），搜索时自动替换为实际日期（不区分大小写，仅在 after 值内替换，不误伤普通文本）；
- 操作栏「📌」把任意条目**置顶/取消置顶**（排在普通条目前）；「📅」把 after 日期整体替换为一月前再搜索；
- 导出时若检测到内置语法会**询问**：替换为实际日期后导出，还是直接导出（保留内置语法）。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展；
2. Tampermonkey → 添加新脚本 → 粘贴 `fofa-toolbox.user.js` 全文 → `Ctrl+S` 保存；
3. Chrome（Manifest V3）需在 `chrome://extensions` → Tampermonkey → 详情中开启「允许运行用户脚本」；
4. 打开 FOFA 任意页面，控制台（F12）应输出 `[FOFA工具箱] v<版本号> 已加载`——右键无反应时先确认该版本号与仓库一致。

## 配置

脚本开头的常量：

- `OPEN_IN_BACKGROUND`：`true` 时新标签页在后台打开。注意：后台打开走 `GM_openInTab`，会丢失 opener 树状关系（前台打开才有）。

## 实现说明（基于 FOFA v5.5 实测 DOM）

- 结果页各字段均为 `<a href="/result?qbase64=...">` 链接，解码后剥掉当前语句、把 `=`/`==` 翻成 `!=` 再追加，值与 FOFA 自身搜索完全一致；
- FOFA 组合链接有两种形态：`当前语句 && 新条件`（前缀拼接）与 `(新条件 && 部分当前语句) && 其余`（括号重组，常见于分类/时间过滤），按顶层分段差集 + 括号内递归提取新增条件；运算符支持单等号（模糊）与双等号（精确），字段名支持带点（`cert.subject.org`）；
- favicon（`img.el-image__inner`）外层就是 icon_hash 链接；
- 国旗（`img.hsxa-country-img`）是内联 SVG、alt 固定为 "country"，从相邻 country 链接取值；
- 世界地图是 ECharts canvas（国家非 DOM 元素、无实例句柄），用悬停 tooltip 提取；
- 「相关Icon」无链接，图标数据在 Vue 组件 props（`keyWord="icon_hash"`, `items[]{key, imageBase64}`）里，从挂载容器 `__vue_app__` 沿 vnode 树下钻读取（Nuxt 根下为 Suspense，需走 `suspense.activeBranch`）；Tampermonkey 沙箱下经 `unsafeWindow` 访问页面世界。
- 注入的样式可能被 FOFA 的 Nuxt 注水清理（表现为刷新后面板退化成页面底部的无样式内容块）：MutationObserver 盯住 head，样式被摘即重挂，另有 2 秒周期检查兜底。
