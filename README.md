# FOFA 工具箱（Tampermonkey 用户脚本）

从一个「右键排除搜索」小脚本起步，现在已经长成覆盖**精准筛选、批量操作、指纹收藏、查询编辑**四个方面的 FOFA 工具箱：

- **右键排除 / 包含**：结果页上几乎任何元素——组件、favicon、国旗、世界地图、侧栏排名条目、划选文本——右键即可把该项作为条件取反（或包含）追加到当前搜索语句；
- **批量操作**：逐条暂存、或 Alt + 左键拖拽框选一片区域，把一批条件一次性全部排除/包含，或作为字段卡**并入查询编辑器**继续加工；
- **指纹收藏库**：把当前搜索语句连同独立 IP 数、产品、类型、国家、Server、Title 等排名信息一键存档，表格式编辑、置顶、搜索过滤、**文件夹分类**（一层）、**快速编辑**（全库去重 / 删除地区）、JSON/CSV 导出与导入，可一键**发送到查询编辑器**继续加工，数据全部存在浏览器本地；
- **查询编辑器**：按**字段分卡**编辑当前语句（或/且拼接、连续排除），底部语句框可直接编辑并与卡片实时互通（**单击语句中的条件可定位上方卡片，聚焦卡片在语句框选中其文本**），支持**命名预设**快插与独立**管理浮层**（新建/编辑/分组/排序/搜索/导入导出/插入/覆盖），一键「一个月内 / 排除云服务」并发起查询，也可从空白新建、把成品**存为指纹**；
- **知识库**：记录厂商**贴牌关系**（母厂 → 贴牌厂商/产品）与各产品的 Server/Title，可**粘贴产品前端截图**，搜索过滤、JSON 导出导入。

指纹库、查询编辑器、知识库合并在**工具箱**窗口的三个标签页里（左下角「🧰 工具箱」按钮或 **Alt+Q** 开关，记住上次使用的标签页）。

## 一、右键排除 / 包含

右键以下对象会弹出条件菜单（**只在识别到这些目标时才接管右键**，其余位置保持浏览器原生菜单；**Shift + 右键** = 强制原生菜单）：

| 右键对象 | 识别来源 |
|---|---|
| 组件 / 产品链接 | 解码链接自身的 qbase64 |
| favicon 图标 | 图标外层自带的 icon_hash 搜索链接 |
| 国旗图片（结果行 / 侧栏统计） | 相邻的 country 搜索链接 |
| 侧栏世界地图上的国家 | 右键时悬停中的地图 tooltip（国家名 / ISO 代码） |
| 侧栏「相关Icon」图标 | Vue 组件数据中的 icon_hash（按图标 base64 匹配条目，精确值） |
| 侧栏各排名条目（分类 / Server / 网站标题 / 证书组织 / 网站指纹 / 协议 / 端口…） | 条目自带链接的 qbase64 |
| 服务器图标 | 图标所在锚点的文本 |
| IP / 端口 / 城市 / ASN / org / domain / header_hash / TLS 版本等链接 | 链接的 qbase64 |
| 划选文本 | 选区内容（国名/协议名自动识别字段） |

菜单能力：

- **🚫 排除并打开**（回车同）：将条件取反后追加到当前语句；**➕ 且包含**（`&&` 追加）与 **➕ 或包含**（`||` 并入）在未编辑时沿用 FOFA 原生运算符（保留 `==` 精确匹配语义）；**或包含**会优先把条件并入语句里**同字段的或组**——插进括号与其他同类条件并列（如多国 `(country="IN" || …)` 再或包含 `country="PK"`，条件落在括号内），组内已有该值则不重复添加；没有可并的或组（或条件不可解析）时把当前语句整体括起来再或，保证 `||` 不因优先级被 `&&` 吞掉；
- 条件在菜单内**可编辑**，改完再排除/包含；
- 当前语句里**已存在的条件**（自引用链接，如当前选中的分类）会**就地取反**而不是追加，避免语句自相矛盾；
- 页脚「在本页打开」开关：勾选后在当前标签页内跳转（默认新标签）；
- 新标签页经 `window.open` 打开，保留 opener 关系——Tree Style Tab 等树状标签插件会将其挂为当前标签的**子标签**。

## 二、批量操作

- **Alt + 左键拖拽框选**：框住一块区域，自动识别其中所有可排除对象（侧栏排名条目/结果行 favicon/国旗/服务器图标/相关Icon）并入批量面板（右下角徽标，跨页面保留，点开可随时增删）；
- 面板内一次「全部排除 / 全部包含并打开」；当前语句里已存在的条件在排除时自动就地取反而不是追加；
- **✏️ 排除到编辑器 / ✏️ 包含到编辑器**：把全部暂存条件作为**字段卡并入查询编辑器**（排除=逐条取反成 `!=` 行，包含=保持原条件；同字段自动集中一卡、去重，工具箱没开会自动打开并切到编辑器标签页），不新开标签，并入后暂存清空——框选一批产品名直接进编辑器逐行微调再搜索。

## 三、指纹收藏库

**收藏（工具箱「＋ 新建」，结果页上会自动抓取当前语句）时填入：**

- **搜索语句**：当前页完整语句；
- **独立 IP 数**：结果头部「N 条独立 IP」；
- **产品**：语句里的 `app=`/`product=` 同义取值优先；否则用产品排名「第一名+同位数」规则；都没有则留空；
- **类型**：分类排名里的名字（不带数量）；
- **国家/地区**：排名「第一名+同位数」规则（如 美国3000/中国2000/印度999 → 美国、中国）；
- **Server / Title**：各取排名第一；
- **收录时间**：收藏当天的系统日期；
- **名称**：仅在产品唯一（语句单产品或排名仅一条）或产品排名第一名位数严格领先时填入，其余留空；
- 「＋ 新建」在结果页同样自动填写，其余页面为空白条目。

**管理面板**（左下角「🧰 工具箱」或 Alt+Q 打开，「指纹库」标签页）：

- 表格含名称/搜索语句/IP数/产品/类型/国家/Server/Title/收录时间/厂商/型号/备注/**文件夹**列，单元格点击即编辑（失焦保存），可任意新建/删除条目；
- **搜索**：顶部搜索框按**任意列内容**实时过滤（名称/语句/产品/厂商/文件夹…），置顶条目仍优先，计数显示「共 N 条，匹配 M 条」；
- **文件夹分类**（一层，不嵌套）：填「文件夹」列即自动分成 📁 组（空=未分组，排最后）；拖动排序限定在同文件夹、同置顶状态内；
- **⚡ 快速编辑**：下拉选择对全库逐条套用的批量操作——🧹 **全库去重**（原语句去重瘦身）、🌏 **删除地区**（去掉每条语句里全部 `country` 条件，或组/单条/排除都删）；每个操作共用「↩ 撤销」整库回退；
- **拖动排序**：拖行首 ⠿ 手柄到目标行的上半/下半即插入到其前/其后（同文件夹内置顶条目仍优先，跨置顶/跨文件夹边界不可放置；导出文件的行顺序即当前显示顺序）；
- ✏️ **发送到查询编辑器**：把该条语句载入查询编辑器继续加工（编辑器此后不再自动跟随页面语句）；
- 🔍 直接用该语句搜索；
- 一键导出 JSON / CSV（CSV 带 BOM，Excel 可直接打开）；
- **🧹 语句去重瘦身**（行内 🧹 单条 / 「⚡ 快速编辑」里的 🧹 全库去重批量）：基于字段卡解析——同一字段存在包含条件（`=`/`==`）时只保留**最后一条**（最终定位条件），该字段的全部 `!=` 中间排除丢弃；纯排除字段是有效过滤，保留并去掉重复行与值为 `-` 的无效条件；`product` 已定位时 `category` 视为冗余一并丢弃（FOFA 产品隶属分类）；或组（多国并列）、关键词原样保留（括号内的跨字段或组会带着括号保住优先级）。单条去重的 **↩ 在该行操作栏**（只恢复本行）；批量操作后工具栏出现「↩ 撤销」可整库回退；
- **导入 JSON / CSV**：与本脚本导出的两种格式对称（表头中文列名或英文字段名均可），按**搜索语句去重合并**——语句为空或已存在的条目（忽略空白差异）自动跳过，完成后提示新增/跳过数量；Excel 在中文 Windows 另存的 ANSI/GBK 编码 CSV 也能自动识别；
- **窗口可拖动、可调尺寸**：按住标题栏移动（位置会记住）；拖右下角把手调宽高（尺寸会记住，默认收矮）；双击标题栏恢复默认尺寸与居中；
- **fofa.info 首页默认自动打开**（居中偏下显示，手动关闭后本次会话不再弹出）；
- 数据存于浏览器 localStorage。

**内置日期语法与置顶：**

- **`after` 值内可使用内置占位语法**：`YESTERDAY`（昨天）、`LastMonth`（一月前，月末日钳制），搜索时自动替换为实际日期（不区分大小写，仅在 after 值内替换，不误伤普通文本）；
- 操作栏「📌」把任意条目**置顶/取消置顶**（排在普通条目前）；「📅」把 after 日期整体替换为一月前再搜索；
- 导出时若检测到内置语法会**询问**：替换为实际日期后导出，还是直接导出（保留内置语法）。

## 四、查询编辑器

工具箱的第二个标签页（Alt+Q 或左下角按钮打开，进入时自动读取当前页语句）：

**按字段分卡编辑**：语句解析后按**字段**聚成一张张「字段卡」。整段被括号包裹的 && 链（如 `((country="PK" || … ) && after="…" && is_cloud="false")`）会先剥开包裹括号再拆分；**括号不配对的语句自动配平**——FOFA 链接里实测会出现开头多一层 `(` 而缺对应 `)`（或多出 `)`），此前会整句塌缩成原样卡，现在缺失的右括号补在末尾（&& 链语义不变）、多余的右括号丢弃、剥不干净的包裹链递归再切。例如
`((country="PK" || … || country="KZ")) && is_cloud="false" && category="视频监控" && product!="HIKVISION-视频监控" && … && after="2026-09-08"`
会得到 5 张卡：country 一张**或卡**（多国并列）、is_cloud / category / after 各一张单值卡、product 一张**且卡**（一串 `!=` 排除值集中在卡内逐行列出）。

- 每张卡：**字段名**（常用字段自动补全，留空即关键词卡）+ **卡内拼接方式**（且 `&&` / 或 `||`，或卡多值合成时自动加括号）；
- 每行值：运算符（模糊 `=` / 精确 `==` / 排除 `!=`）+ 值；「＋值」或 Alt+O 追加（自动继承上一行运算符，适合连续排除）；
- 解析不了的复杂片段以「原样」卡整段保留（括号内的跨字段或组带括号保住优先级）；
- **语句框双向编辑**：底部语句框可直接手工编辑——改动实时解析成上方字段卡，卡片的任何改动也实时回写语句框；失焦时语句框规范化为合成语句（含括号补全，肉眼可见解析结果）；回车搜索，Shift+回车换行；
- **语句框 ↔ 卡片定位联动**：在语句框里**单击**某个条件（或它所在的括号），上方滚动并高亮对应的字段卡，该卡/行同时成为焦点（存预设、Alt+O 追加值的目标跟着光标走）；反过来聚焦一张卡，语句框里会**选中**该卡对应的文本。

**预设**（「📦 预设」按钮展开快插面板，底部「⚙ 管理预设…」进管理浮层）：

- **存为预设看焦点**：焦点在某个**值行**上（点过卡片里的行、或在语句框里点过该条件）→ 只存这一条条件；焦点在**卡头** → 存整卡；无焦点 → 存整条语句——例如名称「地区」、内容 `country="PK" || country="IN" || …`；
- 快插列表**一次点击即插入**：并入当前编辑，**同字段同拼接方式的卡自动合并并去重**——先从页面读入语句，再把「地区」等预设逐个并入，几分钟组织好一次复杂查询；点预设内容本身也可插入；
- **管理浮层**（独立窗口，点外部不会连带关工具箱，Esc 优先关它）：预设结构 =「名称 + 搜索串 + 可选分组（文件夹，一层）」，三者都可改；✏️ 编辑会把该行展开成一份**内嵌卡片编辑器**（与查询编辑器同款，双向同步、括号自动配平）；支持新建、删除、拖 ⠿ 组内排序、搜索过滤、JSON 导出导入（按 名称+搜索串 去重合并）；每行可**插入**（并入编辑器）或**覆盖**（整条替换编辑器内容，覆盖前确认）；
- 预设存在浏览器本地。

**快捷键**：Alt+Q 开关工具箱；**Alt+A** 新增字段卡；**Alt+O** 在焦点卡追加值（继承运算符）；**回车**直接搜索。

**快速开关**（点亮=已生效，再点移除）：📅 一个月内（`after=` 一月前，月末钳制）；☁️ 排除云服务（`is_cloud="false"`，兼容 `is_cloude` 写法）。

**语句来源**：编辑器默认自动跟随页面当前语句（搜索跳转后切回标签页自动重读）；**↻ 使用当前查询语句**显式拉取页面语句（编辑器已有内容先确认）；一旦显式载入过内容（指纹 ✏️ 载入 / 预设覆盖 / **📄 新建空白查询**），就不再自动跟随，想拉页面语句走这个按钮。**🗂 存为指纹**把当前语句直接存入指纹库（自动填名称/产品/收录时间），与指纹库的 ✏️ 发送到编辑器凑成一对。

**搜索**：按当前语句发起查询，遵循右键菜单里「在本页打开」的设置；「📋 复制」只复制不打开。

## 五、知识库

工具箱第三个标签页，记录**厂商贴牌关系**与产品特征，供快速检索：

- 每条记录的字段：**母厂/贴牌自**（如「大华」）、**名称**（贴牌厂商/产品名）、**Server**、**Title**、**备注**、**文件夹**（可选标签列，随导入导出保留、参与搜索过滤；显示仍按母厂自然分组，两者如何融合待后续定）、**产品截图**；
- 表格按「母厂/贴牌自」排序，同一母厂下的贴牌产品**自然形成分组**；组内可**拖动行首 ⠿ 手动排序**（写入可选 `order` 字段，随导出保留，跨组不可放置）；顶部搜索框按 母厂/名称/Server/Title/备注 实时过滤——搜「大华」即列出其下所有贴牌产品；
- 「＋ 新建」在结果页会自动预填：名称（语句里的 `app=`/`product=`）、Server、Title（各取侧栏排名第一），其余页面为空白条目；
- **产品截图**：点击截图列聚焦后 **Ctrl+V** 直接粘贴产品前端截图（或点 📎 选择图片文件），自动压缩为最长边 640px 的白底 JPEG 再存储；缩略图悬停出现 ✕ 删除，点击缩略图全屏查看（点击任意处关闭，Esc 优先关灯箱）；
- 导出/导入 JSON（含截图数据；导入按 母厂+名称+Server+Title 去重合并）；
- 数据与截图都存在浏览器 localStorage——截图较多时注意容量（超限会提示），建议定期导出备份。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展；
2. Tampermonkey → 添加新脚本 → 粘贴 `fofa-toolbox.user.js` 全文 → `Ctrl+S` 保存；
3. Chrome（Manifest V3）需在 `chrome://extensions` → Tampermonkey → 详情中开启「允许运行用户脚本」；
4. 打开 FOFA 任意页面，控制台（F12）应输出 `[FOFA工具箱] v<版本号> 已加载`——右键无反应时先确认该版本号与仓库一致。

## 配置

脚本开头的常量：

- `OPEN_IN_BACKGROUND`：`true` 时新标签页在后台打开。注意：后台打开走 `GM_openInTab`，会丢失 opener 树状关系（前台打开才有）。

## 实现说明（基于 FOFA v5.5 实测 DOM）

- 结果页各字段均为 `<a href="/result?qbase64=...">` 链接，解码后剥掉当前语句、把 `=`/`==` 翻成 `!=` 再追加，值与 FOFA 自身搜索完全一致；
- FOFA 组合链接有两种形态：`当前语句 && 新条件`（前缀拼接）与 `(新条件 && 部分当前语句) && 其余`（括号重组，常见于分类/时间过滤），按顶层分段差集 + 括号内递归提取新增条件；运算符支持单等号（模糊）与双等号（精确），字段名支持带点（`cert.subject.org`）；
- favicon（`img.el-image__inner`）外层就是 icon_hash 链接；
- 国旗（`img.hsxa-country-img`）是内联 SVG、alt 固定为 "country"，从相邻 country 链接取值；
- 世界地图是 ECharts canvas（国家非 DOM 元素、无实例句柄），用悬停 tooltip 提取；
- 「相关Icon」无链接，图标数据在 Vue 组件 props（`keyWord="icon_hash"`, `items[]{key, imageBase64}`）里，从挂载容器 `__vue_app__` 沿 vnode 树下钻读取（Nuxt 根下为 Suspense，需走 `suspense.activeBranch`）；Tampermonkey 沙箱下经 `unsafeWindow` 访问页面世界。
- 注入的样式可能被 FOFA 的 Nuxt 注水清理（表现为刷新后面板退化成页面底部的无样式内容块）：MutationObserver 盯住 head，样式被摘即重挂，另有 2 秒周期检查兜底。
